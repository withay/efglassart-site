Featured

Custom Tableware Commission

A client asked if I could create a coordinated set of fused glass tableware in black and red, using bold angled striping across multiple forms.

The result was a complete table service — including a large platter, serving plates, bowls, trivets, and a spoon rest — all designed to work together visually while remaining fully functional for everyday use.

The collection is continuing to grow, with a full set of dinner plates and smaller bread or dessert plates currently in progress.
